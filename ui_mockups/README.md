# 光剑 UI 原型

## 页面清单

| 文件 | 功能 | 说明 |
|------|------|------|
| `positions.html` | 持仓列表页 | 展示所有持仓、总览卡片、更新按钮 |
| `detail.html` | 个股详情页 | K线图占位、持仓详情、交易建议、相关新闻 |
| `add_position.html` | 新增持仓表单 | 录入股票信息、底仓、多批次波段仓 |

## 设计说明

### 响应式布局
- 使用 Bootstrap 5 框架
- 适配手机、平板、电脑

### 核心交互
1. **持仓列表页**
   - 顶部显示上次更新时间（精确到秒）
   - "更新数据"按钮带 loading 状态
   - 点击卡片"查看详情"进入个股页
   - 右下角悬浮"+"按钮新增持仓

2. **个股详情页**
   - K线图区域（集成 ECharts 后填充）
   - 左侧显示持仓详情和交易建议
   - 右侧显示相关新闻列表
   - 每条新闻有"阅读原文"链接

3. **新增持仓表单**
   - 底仓和波段仓分开录入
   - 波段仓支持添加多批次
   - 实时计算加权成本
