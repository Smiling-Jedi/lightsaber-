# 交易计划模块测试用例

## 一、表单功能测试

### TC-001: 新建交易计划 - 正常流程
**前置条件**: 已登录系统，有实际交易记录
**步骤**:
1. 访问 /trades/ 点击"补录计划"
2. 填写表单：
   - 市场: A股
   - 代码: 159949
   - 策略: 波段
   - 买入价: 1.5
   - 目标价: 1.8
   - 股数: 1000
   - 止损: 固定比例 7%
   - 买入理由: RSI超卖反弹
3. 点击"提交保存"

**预期结果**:
- 自动评估显示
- 列表页显示"已有计划"
- 评分徽章显示（如 85分）

### TC-002: 止损方式联动
**步骤**:
1. 选择"不止损,长期持有"
   - 预期: 参数行隐藏
2. 选择"固定比例"
   - 预期: 显示百分比输入，默认值7
3. 选择"ATR倍数"
   - 预期: 显示倍数输入，默认值2
4. 选择"支撑位"
   - 预期: 显示价格输入，无默认值
5. 选择"移动平均线"
   - 预期: 显示MA下拉，默认MA20

### TC-003: 评估功能 - 高风险
**步骤**:
1. 填写表单，设置止损价远高于买入价（如买入10元，止损15元）
2. 点击"提交保存"

**预期结果**:
- 评估面板显示"高风险"
- 弹出确认对话框
- 可取消或确认提交

### TC-004: 评估功能 - 通过
**步骤**:
1. 填写合理的交易计划
2. 点击"提交保存"

**预期结果**:
- 评估面板显示"建议执行"
- 无确认对话框，直接提交
- 跳转到列表页

## 三、API接口测试

### TC-008: 评估API
```bash
curl -X POST http://127.0.0.1:8080/trades/api/evaluate \
  -d "symbol=A:159949" \
  -d "strategy_type=波段" \
  -d "planned_price=1.5" \
  -d "target_price=1.8" \
  -d "planned_shares=1000" \
  -d "stop_loss_method=固定比例" \
  -d "stop_loss_param=7" \
  -d "buy_reason=测试"
```

**预期结果**: 返回JSON包含evaluation和plan信息

### TC-009: 创建计划API
```bash
curl -X POST http://127.0.0.1:8080/trades/api \
  -d "symbol=A:159949" \
  -d "strategy_type=波段" \
  -d "planned_price=1.5" \
  -d "target_price=1.8" \
  -d "planned_shares=1000" \
  -d "stop_loss_method=固定比例" \
  -d "stop_loss_param=7" \
  -d "buy_reason=测试" \
  -d "trade_id=1"
```

**预期结果**: 重定向到 /trades/
