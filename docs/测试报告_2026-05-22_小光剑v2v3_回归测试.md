## 三、本轮新发现 Bug

### 🟠 Bug-New-001 详情页 console TypeError

**现场**：
```
TypeError: Cannot read properties of null (reading 'classList')
    at switchTab (HK_01888.html:1167:74)
```

**影响范围**：v2 + v3 所有详情页（共 45 个文件）

**根因**：
- `mini/base.html` 第 224 行：页面加载时自动调用 `switchTab(saved)`
- 详情页没有 `.market-tab` 元素
- `document.querySelector('.market-tab[data-market="' + market + '"]')` 返回 null
- 调用 `.classList.add('active')` 报错

**修复**：模板已修复（添加空值检查），静态文件待重新生成后生效
- 不影响用户可见功能（详情页不需要 Tab 切换）
- 但污染控制台，建议下次生成时一并更新

**状态**：🟡 模板已修复，静态文件待重新生成
