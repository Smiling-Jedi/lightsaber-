# 光剑系统 · 投资辅助系统说明

**建立时间**：2026年3月26日
**定位**：以Claude为分析伙伴，基于持仓数据库+投资档案+分析框架，提供持续的持仓健康分析和交易决策辅助

---

## 一、系统目的

Jedi以炒股为唯一经济来源，面临以下核心需求：

1. **定期体检**：持仓横跨港/美/A股三市场、31只标的，人工难以系统性评估健康度
2. **决策辅助**：有交易想法时，需要突破自身认知局限，获得客观专业的第二意见
3. **行为约束**：已知存在追高、处置效应等行为偏差，需要框架和纪律约束
4. **目标追踪**：年化目标25%，需要持续评估当前组合能否达成目标，提前预警

Claude的角色：**不是给指令让你执行，而是基于你的档案+数据+框架，给出客观专业分析，帮你突破自己的认知局限。**

## 二、系统四个组成部分

### 1. 持仓数据库
**路径**：`lightsaber/data/lightsaber.db`

| 数据表 | 内容 |
|--------|------|
| `positions` | 持股：代码、股数、底仓数、成本、波段成本 |
| `cash_balances` | 现金和货基：港币、美元、人民币、货基 |

**数据来源**：
- 港/美股价格：富途OpenD实时接口（最高优先），OpenD不可用时降级Yahoo
- A股价格：截图基线 + 人工更新 + Claude校验
- 持仓变动：每次交易后人工告知Claude更新数据库

**现金计算规则（防重复）**：
```
港币现金 = HK_CASH + HKD_FUND（不加FUND，FUND已含美元折算）
美元现金 = USD_CASH + USD_FUND
总现金(CNY) = 港币现金×0.933 + 美元现金×7.27 + A股现金
```

**持仓分类**：

| 类型 | 止损方式 | 当前持仓 |
|------|---------|---------|
| 底仓 | 逻辑驱动：盈利时设保本止损；基本面恶化时触发审查；不做ATR机械止损 | 腾讯6000、阿里6000、A股全部、美股NVDA/TSLA/META/MSFT100/NFLX/SOFI/AMZN/GOOG/UNH/PDD |
| 波段仓 | ATR机械止损+红绿灯全量检查 | 腾讯1000(成本605.25)、阿里7000(加权成本150.1)、MSFT 50股 |
| 观察仓 | 不做止损，只看逻辑 | CRCL 5股、RKLB 10股（市值≈1000美金以下） |

**跨账户合并原则**：所有仓位占比 = 跨三市场合并市值 ÷ 全部总资金，不按账户单独看。

### 2. 投资档案
**路径**：`~/.claude/projects/.../memory/jedi_investor_profile.md`

记录Jedi的完整投资者画像，Claude跨会话可调用：
- 身份背景（腾讯20年、炒股唯一收入）
- 财务状况（负债328万、储备金缺口60万、无新增资金）
- 投资目标（年化25%、回撤容忍20-30%）
- 交易纪律（底仓/波段/ATR止损/收益黑洞定义）
- 已知行为问题（追高、处置效应、熟悉度偏好）

### 3. 分析框架（两套，可交叉使用）

#### 光剑系统-持仓体检框架-五维雷达
**文件**：`docs/光剑系统-持仓体检框架-五维雷达.md`
**定位**：周频快检，结构性判断，约1小时完成

| 维度 | 测量什么 |
|------|---------|
| 维度一：集中度风险 | HHI + 中概集群 + 3个压力情景 |
| 维度二：波段仓管理 | 买入定量 + 持有红绿灯 + 止损/止盈条件 |
| 维度三：投资逻辑验证 | 逻辑标签 + 机会成本 + 行为自查3问 |
| 维度四：归因分析 | 真实选股能力 vs 行业Beta（季度/年度） |
| 维度五：组合健康度预判 | 现金合理性 + 预期收益 vs 25%目标 |

#### 光剑系统-持仓体检框架-八爪鱼
**文件**：`docs/光剑系统-持仓体检框架-八爪鱼.md`
**定位**：月度/季度深检，8模块全量扫描，更详细

两套框架可交叉使用，互相补充，以后还可以引入新框架。

### 4. 关键输出

#### A. 周频持仓健康报告
- **触发**：每周，Claude读数据库 + 富途实时价格
- **使用框架**：五维雷达（常规）或八爪鱼（季度深检）
- **存档路径**：`docs/持仓体检报告_YYYYMMDD.md`
- **已有报告**：持仓体检报告_20260324.md、持仓体检报告_20260326.md

#### B. 交易决策讨论
- **触发**：Jedi有交易想法时随时发起
- **Claude输出**：基于框架的专业建议，涵盖：
  - 这笔交易对集中度的影响
  - 波段仓的仓位定量计算（基于ATR）
  - 逻辑标签是否支持
  - 机会成本对比
  - 与已知行为偏差的关联提示
- **存档路径**：`docs/交易讨论日志.md`（追加式）

## 三、实用场景

### 场景1：每周体检
> "帮我跑一次五维雷达体检"

Claude读数据库 → 调富途接口取实时价格 → 跑5个维度 → 输出报告 → 保存md文件

### 场景2：交易前讨论
> "我想把中信证券清仓换成阳光电源，你觉得呢？"

Claude基于：当前仓位数据 + 投资档案 + 逻辑标签 + 机会成本分析 → 给出专业建议

### 场景3：止损决策
> "阿里跌到115了，我该不该止损？"

Claude基于：ATR止损规则 + 底仓/波段区分 + 投资逻辑是否仍成立 + 行为自查（是否处置效应）→ 给出判断

### 场景4：加仓评估
> "比亚迪年报超预期，我想加仓5000股，合理吗？"

Claude基于：仓位定量计算 + 加仓后集中度变化 + 逻辑标签验证 → 给出建议和具体操作参数

### 场景5：季度深检
> "帮我做一次季度深检，用八爪鱼框架"

Claude跑完整8模块 + 归因分析（收益来自选股还是Beta）+ Sortino/Calmar比率 → 输出深度报告
