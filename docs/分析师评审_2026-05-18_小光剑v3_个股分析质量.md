## 一、整体结论

| 维度 | 评级 | 说明 |
|------|------|------|
| 形态识别专业度 | ⭐⭐⭐⭐ 接近专业 | 头肩底/双底/上升通道等识别 + 关键点位定位扎实 |
| 操作建议合理性 | ⭐⭐⭐⭐ 实战可用 | 止损/目标/加仓区间表述清晰、有实操性 |
| 三周期共振逻辑 | ⭐⭐⭐ 中等 | 强共振描述模板化太严重；周期冲突的细分判断好 |
| 量价配合解读 | ⭐⭐⭐⭐ 接近专业 | 头放量、突破放量、回踩缩量等术语用得对 |
| **数据一致性** | ⭐⭐ 严重不一致 | 卡片显示成本 ≠ 分析里引用的成本，多处自相矛盾 |
| 基本面引用 | ⭐⭐ 几乎没有 | 标的几乎不引用财报、估值、行业地位等基本面，纯技术面 |

**核心评价**：技术分析达到了准专业水平，**但被数据层 Bug 严重拖累**。同一只股票的成本数字在卡片头部、底仓说明、盈亏百分比里出现 3 个不同值，分析师都会迷惑，更别说普通用户。

## 二、亮点（值得保留 + 扩展）

### 2.1 形态识别扎实
**比亚迪 002594（教科书级）**：
- 日 K：头肩底已确认（左肩 92.70 / 头部 85.88 / 右肩 90.27 / 颈线 111.82）
- 头肩底深度对称性合格（左肩 92.70 > 头部 85.88 < 右肩 90.27，几何形态成立）
- 量度升幅 = 颈线 + (颈线-头部) = 111.82 + 25.94 = **137.76** ✅
- 多周期递进：日 K 已确认 → 周 K/月 K 双底构筑中（短期更快进入突破阶段，符合多周期套娃逻辑）

**粤海投资 00270**：
- 双底 + 上升通道 + 三周期共振 = 5 星推理链合理
- 操作建议梯度清晰：8.51 突破加仓 / 8.00 失效止损 / 9.26 减半止盈 / 10.26 清仓

### 2.2 实战导向的操作建议
不是简单"建议买入/卖出"，而是给出：
- **触发条件**（"放量突破 XX 且站稳 3 个交易日"）
- **保护条件**（"跌破 XX 减仓 / 跌破 YY 清仓"）
- **置信度升降规则**（"如何升为 high / 降为 low"）

这套结构具备**可执行性**，比一般券商研报清晰。

### 2.3 量价配合解读到位
**比亚迪关键描述**：
> "头部区域成交量放大（20260202达64万），右肩反弹放量（20260302达143万），颈线突破日20260323放量178万，符合头肩底'头放量、突破颈线放量'特征；近期回落缩量（20260515仅46万），量价配合合理"

这种**具体到日期+量能**的描述，属于专业技术分析的标配，值得保留。

### 2.4 周期冲突的细化模板
**特斯拉**："日线调整但周线向好，短期回调可能是中期买入机会"

比首页统一模板"各周期信号不一致，方向不明，建议观望"更有价值——它告诉用户**冲突的具体方向**和**可能的解读**。

## 三、需要优化的问题

### 优-001 卡片显示成本 ≠ 分析里引用的成本（最严重）

**特斯拉示例**：
- 卡片头部：「底仓 200@402.7」
- 底仓建议：「底仓成本 353.58 低于当前价 19.4%」
- 反推：(425.27 - 353.58) / 353.58 = +20.3% ✅ 对得上盈亏百分比

**粤海投资示例**：
- 卡片头部：「底仓 74000@7.2」
- 底仓建议：「底仓 74000 股@7.16 已有 +21.4% 浮盈」
- 反推：(8.47 - 6.98) / 6.98 = +21.4% ✅（用了 avg_cost 6.98，**不是 7.16**）

**矛盾**：
- 显示给用户的"成本"是 base_cost（7.16）
- 计算盈亏百分比用的是 avg_cost（6.98）
- 分析里 LLM 写的是 base_cost（7.16）但盈亏是 avg_cost（6.98）算的
- 三处不一致

**修复方向**（产品视角）：
- 选 1 个成本口径统一：建议用**实时加权成本**（base*base_cost + swing*swing_cost）/ total_shares
- avg_cost 字段必须重新核算或弃用
- 分析模板里的成本引用，必须从同一来源取数

### 优-002 三周期共振"看涨"描述模板化过度

**当前问题**：90% 的看涨股票都用同一句"日/周/月三周期同步看涨，短中长期资金达成共识，信号最强"

**遗失的信息**：
- 三周期形态的差异（如比亚迪日 K 头肩底已确认，周月双底构筑中，这种"日确认+周月构筑"是不同于"三周期都已确认"的状态）
- 当前所处的阶段（突破后回踩 / 构筑中 / 已突破等）

**优化方向**：
- 至少区分 3-4 种共振看涨情境：
  1. 全部已确认 → "三周期形态均确立，趋势最强"
  2. 日确认+周月构筑 → "日线领先突破，周月底部待确认，可适度乐观"
  3. 日构筑+周月已确认 → "中长期已立，等待日线发动"
  4. 日突破后回踩 → "日 K 突破后正常回踩，关注支撑有效性"

### 优-003 基本面几乎没有

**现状**：所有详情页几乎不引用：
- 财报数据（EPS、PE、PB、ROE）
- 行业地位（市占率、竞争格局）
- 重大事件（重组、合规、政策影响）
- 估值锚（DCF/可比公司）

**示例**：腾讯（仓位 34.1%，最大持仓）只讲技术形态，对其游戏/广告/金融科技业务、AI 投入、回购节奏、机构持仓变化一字未提。

**建议**：
- 基本面板块作为详情页"多维度验证"的第 4-5 项（在量价/波动/周期之外）
- 至少包含：最近一份财报关键指标 / 当前估值水平（PE 与历史对比）/ 关键事件（如有）

### 优-004 评分和风险标的逻辑不一致

| 股票 | 共振 | 评分 | 风险标 |
|------|------|------|--------|
| MSFT 微软 | ⭐⭐⭐⭐⭐ 看涨 | 6.0 | 无 |
| NVDA 英伟达 | ⭐⭐⭐⭐⭐ 看涨 | 6.7 | 无 |
| LITE Lumentum | ⭐⭐⭐⭐⭐ 看涨 | 6.3 | **⚠️ 高** |
| RKLB Rocket Lab | ⭐⭐⭐⭐⭐ 看涨 | 7.3 | 无 |
| CRCL Circle | ⭐⭐⭐⭐⭐ 看涨 | 6.0 | **⚠️ 高** |
| 比亚迪 | ⭐⭐⭐⭐⭐ 看涨 | 6.7 | **⚠️ 风险 中** |

**问题**：
- 共振一致看涨的情况下，评分相近（6.0-6.7），但风险标差异巨大
- 无法从公开维度推断"为什么 MSFT 无风险标但 LITE 有"
- 用户会困惑判断标准

**建议**：
- 风险标的来源应该明确（波动率？估值？财报？仓位比例？）
- 评分构成的公式要透明（form_completeness + volume_match + key_level_distance 平均，但具体到每只股票怎么得分？）
- 在详情页能展开看到"评分是怎么得来的"

### 优-005 ETF 缺失分析未明确说明

医药ETF 易方达 / 机器人ETF 华夏 显示"暂无形态分析"。

**问题**：用户不知道是"该不该有，是 Bug"还是"ETF 不参与，是设计"。

**建议**：
- 若是产品决策：文案改为「ETF 标的不做形态分析，建议跟踪指数表现」
- 若是 Bug：补跑形态分析数据

## 五、给研发的修复建议（按优先级）

### P0 — 数据层根因（影响 70% 详情页可信度）
1. 修复 `Position.avg_cost` 错乱：
   - 方案 A：脚本根据 base_shares、base_cost、swing_shares、swing_cost 重新批量计算 avg_cost 入库
   - 方案 B：mini_router 不再读 avg_cost，实时计算 `(base*base_cost + swing*swing_cost) / total_shares`
   - **推荐方案 B**：避免数据库字段持续被同步逻辑写坏，从计算源头消除问题
2. 修复 LITE 价格异常（核查 iFinD 拉取代码是否正确，是否做了错误复权）
3. 处理 swing_shares 为负数的边缘情况（CRCL: total=5/swing=-5、中信证券 swing=-3000）

### P1 — 模板与展示
4. 卡片显示成本和分析引用成本统一来源
5. 三周期共振"看涨"描述按形态阶段分 3-4 档
6. 风险标 ⚠️ 触发规则明确并显示

### P2 — 内容丰富
7. 增加基本面板块（财报关键指标 + 估值 + 重大事件）
8. ETF 明确"不做形态分析"或补齐数据
