# 讨论记录：建议买入价如何确定

**时间：** 2026-03-31
**参与人：** Jedi、Claude
**主题：** T+1限价单模式下，建议买入价（limit_price）的具体计算逻辑

---

## 一、背景

已确定采用 **T+1限价单模式**：
- T日盘后原力模块生成BUY信号，给出建议买入价
- T+1日只要最低价≤建议买入价，就按建议买入价成交
- 需要明确定义"建议买入价"的计算逻辑

---

## 二、原力模块的策略定义（已确认）

根据 `signal_service.py` 代码和用户提供截图：

| 策略类型 | 触发条件 |
|----------|----------|
| **cyclical**（周期股） | RSI<40 且 价格≤布林下轨 |
| **defensive**（防御股） | 价格≤布林下轨×1.015 |
| **large_tech**（大科技） | EMA金叉 |
| **biotech**（医药） | RSI<30 |

---

## 三、待讨论问题

### 问题核心：
> 建议买入价应该 **等于触发价**、**比触发价更保守**、还是 **比触发价更激进**？

### 场景分析：

#### 场景1：cyclical（周期股）
- 触发条件：价格 ≤ 布林下轨
- 当前方案建议价：布林下轨
- **问题：** T日收盘价可能远低于布林下轨，建议价是否应该更低？

#### 场景2：defensive（防御股）
- 触发条件：价格 ≤ 布林下轨×1.015
- 当前方案建议价：布林下轨
- **问题：** 布林下轨比"下轨×1.015"更严格（更低），是否太保守？

#### 场景3：large_tech（大科技）
- 触发条件：EMA金叉（趋势向上）
- 当前方案建议价：T日收盘价
- **问题：** EMA金叉是追涨信号，建议价是否应该≥收盘价？还是允许一定回调？

#### 场景4：biotech（医药）
- 触发条件：RSI<30（极度超卖）
- 当前方案建议价：收盘价×0.97（预留3%空间）
- **问题：** 3%预留是否合理？是否应直接按收盘价？

---

## 四、可选方案

### 方案A：完全匹配触发条件
建议买入价 = 触发条件的临界价格

```python
cyclical:    limit_price = 布林下轨
defensive:   limit_price = 布林下轨 × 1.015
large_tech:  limit_price = T日收盘价（金叉时价格）
biotech:     limit_price = T日收盘价（RSI<30时价格）
```

**优点：**
- 逻辑清晰，建议价就是触发价
- 不抢跑也不滞后

**缺点：**
- 对于cyclical，如果T日收盘价远低于下轨，建议价可能远高于实际可买价
- 可能买不到（T+1日价格反弹）

---

### 方案B：保守策略（确保买到）
建议买入价 = 比触发条件更宽松的价格

```python
cyclical:    limit_price = min(布林下轨, T日收盘价)  # 如果已跌破，按收盘价
defensive:   limit_price = 布林下轨  # 比"下轨×1.015"更低，更保守
large_tech:  limit_price = T日收盘价 × 1.01  # 允许1%追涨
biotech:     limit_price = T日收盘价 × 0.95  # 预留5%空间
```

**优点：**
- 提高成交概率
- 对于已经超跌的股票，不会追高

**缺点：**
- 可能偏离原策略意图
- 需要为每种策略定义"保守系数"

---

### 方案C：跟随策略（动态调整）
建议买入价基于T日实际收盘价和触发条件的关系

```python
cyclical:
    if T日收盘价 < 布林下轨:
        limit_price = T日收盘价  # 已经跌破，按收盘价买
    else:
        limit_price = 布林下轨   # 刚好触及，按下轨买

defensive:
    if T日收盘价 < 布林下轨 × 1.015:
        limit_price = T日收盘价
    else:
        limit_price = 布林下轨 × 1.015

large_tech:
    # EMA金叉是追涨，稍微放宽
    limit_price = max(T日收盘价, 金叉形成时的价格)

biotech:
    # RSI<30是极值，预留回调空间
    limit_price = min(T日收盘价 × 0.97, 布林下轨)
```

**优点：**
- 灵活，根据实际走势调整
- 避免追高或错过

**缺点：**
- 逻辑复杂
- 实盘复制时需要人工判断

## 五、待决策事项

| 策略类型 | 选项A<br>（匹配触发价） | 选项B<br>（保守） | 选项C<br>（动态） |
|----------|----------------------|------------------|------------------|
| cyclical | 布林下轨 | 收盘价/下轨孰低 | 根据收盘价调整 |
| defensive | 下轨×1.015 | 布林下轨 | 根据收盘价调整 |
| large_tech | 收盘价 | 收盘价×1.01 | 金叉价/收盘价孰高 |
| biotech | 收盘价 | 收盘价×0.95 | 收盘价×0.97/下轨孰低 |

## 六、关键考量因素

1. **成交概率 vs 策略纯度**
   - 建议价太保守：可能偏离原策略信号
   - 建议价太激进：可能买不到，信号浪费

2. **实盘可复制性**
   - 复杂的动态逻辑难以在券商APP中手动复制
   - 简单明确的价格更容易挂限价单

3. **滑点统计**
   - 无论选哪种，长期记录"建议价 vs T+1开盘价"的偏差
   - 用于后续修正模拟收益
