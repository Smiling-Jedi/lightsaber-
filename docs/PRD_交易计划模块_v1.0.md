## 1. 项目背景

### 1.1 用户画像
Jedi 是一位资深投资者，具有以下特征：
- **资金规模**: ~1300-1400万
- **核心诉求**: 克服"追高"、"止损迟疑"、"纪律性不足"等行为问题
- **双策略架构**:
  - 策略A（底仓波段）: 腾讯/阿里/宁德等个股，底仓用基本面止损，波段用ATR机械止损
  - 策略B（ETF轮动）: 创业板50ETF等，按周度评分调仓
- **当前约束**: 储备金缺口60万，需优先减仓补足

### 1.2 问题痛点
1. 买入前没有明确计划，容易冲动交易（追高）
2. 止损不坚决，被套后想等回本（处置效应）
3. 交易后缺乏复盘，难以积累经验

### 1.3 解决方案
开发**交易计划模块**，强制买入前填写计划，系统评估风险，事后支持复盘。

## 3. 数据库设计

### 3.1 主表 `trade_plans`

```sql
CREATE TABLE trade_plans (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    trade_id INTEGER,                    -- 关联 trades 表（买入后回填）
    
    -- 基础信息
    symbol VARCHAR(20) NOT NULL,         -- 股票代码，如 A:300274
    market VARCHAR(10) NOT NULL,         -- 市场：A/US/HK
    strategy_type VARCHAR(20) NOT NULL,  -- 策略：底仓/波段
    
    -- 交易参数
    planned_shares INTEGER NOT NULL,     -- 计划买入股数
    planned_price DECIMAL(15,4) NOT NULL,-- 计划买入价/触发价
    target_price DECIMAL(15,4) NOT NULL, -- 目标价
    
    -- 止损设置
    stop_loss_method VARCHAR(20) NOT NULL,   -- 止损方式：固定比例/ATR倍数/支撑位/移动平均线
    stop_loss_param DECIMAL(10,4) NOT NULL,  -- 参数值：比例%/ATR倍数/价格/天数
    stop_loss_price DECIMAL(15,4) NOT NULL,  -- 最终止损价
    
    -- 风险评估（自动计算）
    risk_amount DECIMAL(15,2),           -- 亏损金额 = (买入价-止损价) × 股数
    risk_reward_ratio DECIMAL(5,2),      -- 盈亏比
    
    -- 决策依据
    buy_reason TEXT NOT NULL,            -- 买入理由
    note TEXT,                           -- 补充说明（催化事件、持有期等）
    
    -- 状态管理
    status VARCHAR(20) DEFAULT '计划中', -- 计划中/已执行/已复盘
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    executed_at DATETIME,                -- 实际执行时间
    reviewed_at DATETIME,                -- 复盘时间
    review_note TEXT,                    -- 复盘总结
    
    FOREIGN KEY (trade_id) REFERENCES trades(id)
);

-- 索引
CREATE INDEX idx_trade_plans_symbol ON trade_plans(symbol);
CREATE INDEX idx_trade_plans_status ON trade_plans(status);
CREATE INDEX idx_trade_plans_created ON trade_plans(created_at);
```

### 3.2 字段详细说明

#### strategy_type（策略类型）
| 选项 | 说明 | 默认止损方式 |
|------|------|-------------|
| 底仓 | 长期持有，基本面驱动 | 固定比例（20%）|
| 波段 | 短期交易，技术面驱动 | ATR倍数（2×）|

> 注：ETF轮动策略不在此模块管理，在独立ETF轮动模块

#### stop_loss_method（止损方式）
| 选项 | 参数含义 | 止损价计算 |
|------|---------|-----------|
| 固定比例 | 下跌百分比 | 买入价 × (1 - 参数%) |
| ATR倍数 | ATR倍数 | 买入价 - (参数 × ATR14) |
| 支撑位 | 支撑价格 | 直接 = 参数 |
| 移动平均线 | MA天数 | 当前MA参数值 |

#### 表单字段校验
| 字段 | 必填 | 校验规则 |
|------|------|---------|
| symbol | 是 | 格式：A:xxxxxx / HK:xxxxx / US:xxxxx |
| strategy_type | 是 | 单选：底仓/波段 |
| planned_price | 是 | > 0 |
| target_price | 是 | > planned_price（目标价必须高于买入价）|
| planned_shares | 是 | > 0，整数 |
| stop_loss_method | 是 | 四选一 |
| stop_loss_param | 是 | 根据方式不同：<br>- 固定比例：1-50<br>- ATR倍数：1-5<br>- 支撑位：< planned_price<br>- 移动平均线：5/10/20/60 |
| buy_reason | 是 | 最少10个字 |

#### 自动计算逻辑
1. **止损价计算**
   ```python
   if stop_loss_method == '固定比例':
       stop_loss_price = planned_price * (1 - stop_loss_param / 100)
   elif stop_loss_method == 'ATR倍数':
       atr14 = get_atr14(symbol)  # 从数据服务获取
       stop_loss_price = planned_price - (stop_loss_param * atr14)
   elif stop_loss_method == '支撑位':
       stop_loss_price = stop_loss_param
   elif stop_loss_method == '移动平均线':
       ma_value = get_ma(symbol, stop_loss_param)  # 如 MA20
       stop_loss_price = ma_value
   ```

2. **风险金额**
   ```
   risk_amount = (planned_price - stop_loss_price) * planned_shares
   ```

3. **盈亏比**
   ```
   profit = target_price - planned_price
   loss = planned_price - stop_loss_price
   risk_reward_ratio = profit / loss
   ```

4. **占总资产**
   ```
   total_assets = get_total_assets()  # 从 portfolio 获取
   pct = risk_amount / total_assets * 100
   ```

#### 策略与止损方式联动
| 策略类型 | 默认止损方式 | 可选止损方式 |
|---------|-------------|-------------|
| 底仓 | 固定比例（20%）| 固定比例、支撑位、移动平均线 |
| 波段 | ATR倍数（2×）| ATR倍数、固定比例、支撑位、移动平均线 |

### 4.3 评估结果页（提交后显示）

#### 评估维度
提交计划后，系统从以下维度自动评估：

| 维度 | 权重 | 评估内容 |
|------|------|---------|
| 储备金检查 | 高 | 储备金缺口60万，买入会消耗现金，优先级低 |
| 仓位红线 | 高 | 单票>25%、TOP3>50%、同板块过度集中 |
| 风险金额 | 中 | 单笔止损风险应<总资产1% |
| 盈亏比 | 中 | 建议>2:1，<1:1不建议 |
| 策略匹配 | 低 | 底仓要有基本面理由，波段要有技术面信号 |

> **定位**：与买入计划对应，管理持仓卖出决策，确保利润锁定和及时止损

### 5.1 功能概述

| 功能 | 说明 | 优先级 |
|------|------|--------|
| 卖出计划列表 | 展示所有卖出计划（按日期/股票分组） | P0 |
| 新建卖出计划 | 为持仓创建卖出计划，设定止盈/止损条件 | P0 |
| 关联买入计划 | 卖出计划可关联原始买入计划，追踪盈利实现度 | P1 |
| 自动评估 | 评估卖出合理性（盈利实现度、剩余仓位、趋势匹配） | P0 |

### 5.2 数据模型 `sell_plans`

```sql
CREATE TABLE sell_plans (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    buy_plan_id INTEGER,                 -- 关联买入计划（可选）
    position_id INTEGER,                 -- 关联持仓
    
    -- 基础信息
    symbol VARCHAR(20) NOT NULL,         -- 股票代码
    market VARCHAR(10) NOT NULL,         -- 市场：A/US/HK
    
    -- 卖出参数
    planned_shares INTEGER NOT NULL,     -- 计划卖出股数
    planned_price DECIMAL(15,4),         -- 计划卖出价（止盈目标）
    original_target_price DECIMAL(15,4), -- 原买入时的目标价（参考）
    
    -- 卖出触发逻辑
    sell_trigger_method VARCHAR(20) NOT NULL,  -- 固定比例止盈/ATR倍数/压力位/移动平均线
    sell_trigger_param DECIMAL(10,4) NOT NULL, -- 参数值
    
    -- 卖出类型
    sell_type VARCHAR(20) DEFAULT '止盈',      -- 止盈/止损/调仓/其他
    
    -- 盈利计算（自动）
    estimated_profit DECIMAL(15,2),      -- 预计盈利金额
    estimated_profit_pct DECIMAL(5,2),   -- 预计盈利比例
    target_achievement_pct DECIMAL(5,2), -- 原目标达成度 %
    
    -- 决策依据
    sell_reason TEXT NOT NULL,           -- 卖出理由
    note TEXT,                           -- 补充说明
    
    -- 状态管理
    status VARCHAR(20) DEFAULT '计划中', -- 计划中/已执行/已过期
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    executed_at DATETIME,
    executed_price DECIMAL(15,4),        -- 实际卖出价
    actual_profit DECIMAL(15,2),         -- 实际盈利
    
    FOREIGN KEY (buy_plan_id) REFERENCES trade_plans(id),
    FOREIGN KEY (position_id) REFERENCES positions(id)
);
```

### 5.3 卖出触发逻辑

| 触发方式 | 参数含义 | 触发条件 | 适用场景 |
|----------|---------|---------|---------|
| **固定比例止盈** | 涨幅百分比 | 现价 ≥ 买入价 × (1 + 参数%) | 目标价明确，机械止盈 |
| **ATR倍数止盈** | ATR倍数 | 现价 ≥ 买入价 + (参数 × ATR14) | 趋势跟踪，动态止盈 |
| **压力位** | 阻力价格 | 触及压力位后回落 | 技术派，关键阻力位 |
| **移动平均线** | MA天数 | 跌破MA均线 | 趋势转折确认 |
| **固定比例止损** | 跌幅百分比 | 现价 ≤ 买入价 × (1 - 参数%) | 保护本金，强制止损 |

### 5.5 评估维度

| 维度 | 权重 | 评估内容 |
|------|------|---------|
| **盈利实现度** | 高 | 卖出价 vs 原目标价的完成比例 |
| **剩余仓位合理性** | 高 | 卖出后是否低于25%红线 |
| **卖出逻辑匹配** | 中 | 卖出理由是否与触发方式一致 |
| **机会成本** | 低 | 卖出后资金是否有更好配置 |
