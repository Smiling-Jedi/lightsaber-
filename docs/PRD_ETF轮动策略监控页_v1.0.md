### 2.2 三因子模型
| 因子 | 权重 | 计算逻辑 | 核心含义 |
|------|------|----------|----------|
| **乖离动量** | 30% | 价格/20日均线，再对结果做25日线性回归斜率 | 价格偏离均线的速度 |
| **斜率动量** | 30% | 标准化价格的20日线性回归斜率 × R² | 涨得快且涨得稳 |
| **效率动量** | 40% | 净涨幅 / 期间总波动幅度 | 上涨的"费力程度" |

### 2.3 评分与调仓规则
1. **Z-Score标准化**: 三因子分别标准化后加权合成总分
2. **防抖动机制**: 新第一名得分 > 当前持有得分 × 1.5 才触发调仓
3. **交易时点**: 周五收盘后计算信号，周一开盘执行

### 4.2 数据流
1. **每周五 15:30**: 系统拉取4只ETF日线数据
2. **每周五 16:00**: 自动计算三因子得分，生成信号
3. **每周五 16:30**: 推送信号通知（可选飞书/邮件）

5. **下周一 15:00**: 拉取实际收盘价，记录实际成交，计算滑点

## 七、附录

### 7.1 三因子计算公式

**乖离动量因子 (Bias Momentum)**
```python
bias = close / close.rolling(20).mean()
bias_recent = bias.iloc[-25:]
# 对bias_recent做线性回归，斜率×10000为得分
```

**斜率动量因子 (Slope Momentum)**
```python
prices = close.iloc[-20:] / close.iloc[-20]  # 标准化
slope = LinearRegression().fit(x, prices).coef_[0]
r_squared = LinearRegression().fit(x, prices).score(x, prices)
score = 10000 * slope * r_squared
```

**效率动量因子 (Efficiency Momentum)**
```python
pivot = (open + high + low + close) / 4
momentum = 100 * log(pivot[-1] / pivot[0])
direction = abs(log(pivot[-1]) - log(pivot[0]))
volatility = sum(abs(diff(log(pivot))))
efficiency_ratio = direction / volatility
score = momentum * efficiency_ratio
```
