## 实盘操作Checklist

### 周五晚上
1. [ ] 运行 `etf_strategy_6variations_ifind.py` 计算排名
2. [ ] 记录当前持仓 vs 目标持仓（周五排名第1的ETF）
3. [ ] 检查是否触发1.5倍阈值条件

### 下周一 14:50-15:00
1. [ ] 如当前持仓 ≠ 目标持仓：
   - [ ] 以**收盘价**卖出当前持仓
   - [ ] 以**收盘价**买入目标ETF（周五排名第1）
2. [ ] 如当前持仓 = 目标持仓：保持不动
