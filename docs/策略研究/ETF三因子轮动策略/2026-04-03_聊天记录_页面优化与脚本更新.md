## 一、页面优化设计

### 1.1 设计目标
优化 ETF 策略监控页 (https://smiling-jedi.github.io/etf-dashboard-/)，要求：
- 保持简洁，非必要信息隐藏
- 方便手机查看
- 添加策略说明和计算过程

### 1.2 设计迭代过程

**初版设计稿** (`etf_dashboard_v2.html`):
- 问题：过于复杂，展示信息过多

**第二版** (`etf_dashboard_v3.html`):
- 策略标识：周五盘后打分|下周一收盘前10分钟买卖|1.5倍阈值
- 回测指标：以灰色小字显示在头部（不占版面）
- 页面顺序：当前持仓 → 本周评分排名 → 交易建议 → 交易记录
- 交易建议：包含本周阈值计算过程
- 交易记录：只显示最近1条，点击"查看更多记录"展开

**最终确认的布局**:
```
头部（策略标识 | 6指标 | 日期）
当前持仓
本周评分排名（排名/ETF/周涨跌/得分）
交易建议（含阈值计算过程）
交易记录（可展开）
```

### 1.3 设计稿位置
- 备份文件：`etf-dashboard/design.html`

## 二、update_dashboard.py 更新

### 2.1 问题识别
原 `update_dashboard.py` 生成的是旧布局页面，需要：
1. 添加策略说明和回测指标
2. 修改页面顺序
3. 添加阈值计算过程
4. 交易记录支持展开

### 2.2 评分逻辑验证
确认 `update_dashboard.py` 与 `策略3收盘版.py` 的评分逻辑一致：
- ✅ 三因子权重相同（乖离30%、斜率30%、效率40%）
- ✅ 因子计算公式相同
- ✅ Z-Score 标准化方法相同

### 2.3 更新内容
修改 `generate_html()` 函数：
- 头部添加策略标识和回测指标
- 页面顺序调整为：当前持仓/评分排名/交易建议/交易记录
- 交易建议卡片添加阈值计算过程（当前得分/第1名得分/阈值条件/判断结果）
- 交易记录只显示最近1条，支持点击展开更多

### 2.4 快捷命令
快捷命令 `更新ETF数据.command` 无需修改，继续可用：
```bash
cd /Users/jediyang/ClaudeCode/Project-Makemoney/etf-dashboard
python3 update_dashboard.py
```

## 四、后续使用

### 4.1 周五操作流程
1. 双击运行 `更新ETF数据.command`
2. 脚本自动获取数据 → 计算三因子 → 生成页面 → Git推送
3. 手机访问网页查看最新排名和交易建议

### 4.2 页面展示内容
- **当前持仓**：显示持仓ETF、数量、成本、收益
- **本周评分排名**：4只ETF的排名、周涨跌、得分
- **交易建议**：SIGNAL（HOLD/BUY）+ 计算过程
- **交易记录**：最近交易，可展开查看更多
