## 二、关键Bug发现与修复过程

### 2.1 数据泄露Bug

**问题发现**:  
- 6-variations版本跑出11.89x
- 17x版本跑出17.39x
- 两者逻辑表面相同，但结果差异巨大

**Bug定位**:  
```python
# 6-variations原版（错误）
df_recent = df.iloc[-MOMENTUM_DAY:].copy()  # 用了完整数据df

# 修复后
df_recent = df_hist.iloc[-MOMENTUM_DAY:].copy()  # 用过滤后的df_hist
```

**修复结果**: 从11.89x提升至**17.39x**

### 2.2 阈值判断Bug

**问题**: `select_with_threshold()`返回元组，但`run_strategy()`只解包一个值

**修复**:
```python
# 修复前
target = select_func(factors, holding)

# 修复后
target, should_trade = select_func(factors, holding)
if should_trade and target != holding:
```

## 四、最优策略确定

### 4.1 推荐策略：策略3收盘版

**规则**: 周五收盘后计算排名 → 下周一14:50-15:00收盘执行买卖

**回测数据**:
- 期末净值: **16.36x**
- 年化收益: **47.50%**
- 最大回撤: -26.65%
- 夏普比率: 1.57
- 交易次数: 99次

### 4.2 为什么选策略3收盘版？

**Jedi提问**: "策略3收盘版本这个策略，是周五收盘后出排名，周一快收盘时买卖，我是这么理解"

**确认**: 这个理解完全正确且可行！

```
周五 15:00 收盘 → 计算排名 → 确定下周一买入目标
    ↓
周末
    ↓
下周一 09:30 开盘 → 已知要买什么
    ↓
下周一 14:50 → 卖出旧持仓 + 买入新目标（收盘价成交）
```

### 4.3 与策略2对比

| 指标 | 策略2 | 策略3收盘版 | 差异 |
|------|-------|------------|------|
| 期末净值 | 15.35x | **16.36x** | +1.01x |
| 年化收益 | 46.20% | **47.50%** | +1.30% |
| 最大回撤 | -18.54% | -26.65% | 策略3更激进 |
| 夏普比率 | **1.60** | 1.57 | 策略2更稳健 |
| 胜率 | **57.1%** | 54.1% | 策略2更高 |

**结论**: 策略3收盘版收益更高，虽回撤大8%，但可接受。
