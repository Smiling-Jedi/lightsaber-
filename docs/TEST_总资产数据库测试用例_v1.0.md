# 光剑系统总资产数据库测试用例 v1.0

**测试范围**: 总资产数据存储、同步、计算、历史追溯  
**测试日期**: 2026-04-03  
**测试人员**: QA工程师  
**版本**: v1.0

---

## 一、测试概述

### 1.1 测试目标
验证光剑系统总资产数据库的核心功能：
- 持仓数据准确性（A股/港股/美股）
- 底仓/波段分离计算
- 汇率历史记录
- 审计日志完整性
- 数据一致性保护

### 1.2 测试范围

| 模块 | 测试重点 |
|------|----------|
| 持仓同步 | 港/美股自动同步、A股手动录入 |
| 底仓/波段 | 手动设置、独立成本计算 |
| 现金余额 | 各市场现金、货币基金 |
| 汇率管理 | 历史汇率、实时汇率 |
| 审计日志 | 变更追溯、异常检测 |
| 资产快照 | 每日固化、历史重算 |
