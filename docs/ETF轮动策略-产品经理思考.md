# ETF轮动策略 - 产品经理思考记录

## 一、背景理解

Jedi 在聚宽平台发现一篇关于4只ETF+3因子的量化文章，经过独立回测验证后，发现**周频交易节奏**可带来**17倍收益**（7年年化48.6%）。目前已用10万实盘验证，处于第2周。

现有网页已实现：
- 每周评分排名（4只ETF得分排序）
- 交易建议（BUY/HOLD/SELL信号）
- 当前持仓展示
- 策略表现回测数据
- 交易记录

---

## 二、核心问题分析

### 1. 这个策略的特殊性
| 维度 | 特征 | 产品启示 |
|------|------|----------|
| 频率 | 周度调仓 | 低频，适合上班族，不需要盯盘 |
| 标的 | 4只ETF | 分散度高，单只风险可控 |
| 决策 | 三因子打分 | 规则明确，可解释性强 |
| 验证 | 7年回测+实盘 | 有历史数据支撑，但仍需观察实盘滑点 |

### 2. 当前网页的不足
- **数据孤岛**：盈亏数据需手工维护，与光剑系统真实持仓脱节
- **归因缺失**：看不到每只ETF的三个因子具体得分
- **复盘困难**：缺乏历史信号记录、净值曲线、调仓胜率统计
- **心理锚点缺失**：没有展示"如果不按信号操作会亏多少"

### 3. 用户真实诉求（推测）
Jedi 作为量化实践者，这个页面需要回答的核心问题：
1. **本周该买哪只？** → 已有排名，但可强化信号强度
2. **我现在持仓对吗？** → 需与光剑系统打通，自动同步
3. **这个策略真的靠谱吗？** → 需增加实盘跟踪 vs 回测理论值的对比
4. **我执行到位了吗？** → 需记录每次信号的实际执行情况（滑点、延迟）

## 三、需求优先级判断

| 优先级 | 需求 | 理由 |
|--------|------|------|
| P0 | 光剑系统持仓打通 | 消除手工维护，是"实盘验证"的基础 |
| P1 | 三因子得分明细 | 策略核心，理解决策依据 |
| P1 | 历史信号记录 | 复盘需要，验证执行力 |
| P2 | 净值曲线可视化 | 心理账户，强化信心 |
| P2 | 理论vs实盘收益对比 | 发现滑点成本，优化执行 |
| P3 | 信号推送提醒 | 防止忘记周一开盘操作 |

---

## 四、关键产品决策

### 决策1：数据源
- **持仓/盈亏**：从光剑系统读取真实数据（而非手工录入）
- **ETF价格**：优先同花顺iFinD，次选Tushare/Yahoo
- **因子计算**：需确认原策略的三个因子公式，本地复现

### 决策2：页面形态
- 保持独立网页形式（便于分享/演示）
- 但后端数据与光剑系统打通（避免重复维护）

### 决策3：交互节奏
- 周五收盘后：系统自动打分，推送信号预览
- 周一开盘前：用户确认操作，系统记录计划
- 周一收盘后：系统拉取真实成交，计算滑点
