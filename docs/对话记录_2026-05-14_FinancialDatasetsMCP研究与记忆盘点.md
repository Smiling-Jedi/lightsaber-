## 一、Financial Datasets MCP 研究

### 背景

Jedi 在 X 上看到一篇文章，介绍 Claude Code 可通过 MCP 协议接入 Financial Datasets 金融数据库，可分析全球 17,000+ 股票、30+ 年财务数据。Jedi 要求研究是否适合光剑系统。

### 研究结果

| 维度 | 详情 |
|------|------|
| 数据覆盖 | 美股完整（股价、财报三张表、SEC filings、新闻、内部人交易）+ 加密货币 |
| 港股/A股 | ❌ 无明确支持，所有示例均为美股 |
| 可用工具 | 股价查询、财报、估值指标（P/E/EV）、SEC filings、新闻、股票筛选 |
| 定价 | **$200/月起**，无免费 tier；Pro $2,000/月；Enterprise 定制 |
| 安装命令 | `claude mcp add --transport http financial-datasets https://mcp.financialdatasets.ai/` |

### 对光剑系统的适用性

| 持仓 | 覆盖 | 说明 |
|------|------|------|
| SOFI | ✅ | 美股完整支持 |
| 腾讯/阿里/小米（港股） | ❌ | 无港股支持 |
| 阳光电源/比亚迪（A股） | ❌ | 无A股支持 |
| 创业板50ETF/纳指ETF | ❌ | 无A股ETF支持 |

### 决策

**结论**：$200/月对于单只美股持仓（SOFI）性价比极低，且对港股/A股零覆盖。已卸载。

```bash
# 安装（已执行）
claude mcp add --transport http financial-datasets https://mcp.financialdatasets.ai/

# 卸载（已执行）
claude mcp remove financial-datasets
```

**替代方案**：SOFI 分析继续使用现有工具链（yfinance + SEC EDGAR API + 同花顺 iFinD）。
