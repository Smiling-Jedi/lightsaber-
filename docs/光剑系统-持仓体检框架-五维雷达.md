建立时间：2026年3月26日

## 计算基础

**所有仓位占比 = 跨账户合并持仓市值 ÷ 全部总资金**
- 三市场（港/美/A）合并，折算人民币
- 同一公司跨账户持仓合并计算（如阿里港股+美股ADR）
- 分母包含：持仓市值 + 现金 + 货基

## 五个维度

### 维度一：集中度风险

**HHI（赫芬达尔指数）**
```
HHI = Σ(每股权重)²
有效持仓数 = 1 / HHI
```
- HHI > 0.15 → 关注
- HHI > 0.20 → 触发再平衡审查

**中概风险集群**（合并计算，非独立5只）
- 腾讯 + 阿里 + 美团 + 小米 + PDD
- 集群警戒线：> 55%

**3个标准压力情景**
1. 中概集群 -40% → 总仓回撤多少？
2. 美股科技（NVDA/TSLA/META） -30% → 总仓回撤多少？
3. A股新能源（宁德/比亚迪/阳光） -30% → 总仓回撤多少？

---

### 维度二：波段仓管理

**买入前：仓位定量计算**
```
最大波段仓位 = 风险金额 ÷ ATR止损距离%
风险金额建议 = 总仓 × 1-2%
```

**持有中：红绿灯（3问）**

| 问题 | 绿 | 黄 | 红 |
|------|----|----|-----|
| 价格在60日均线上方？ | 是 | 勉强 | 否 |
| 近30天跑赢所在市场指数？ | 是 | 持平 | 跑输>10% |
| 仓位未超警戒线？ | 是 | 临近 | 超了 |

**卖出条件**
- 止损：ATR止损位触发 → 执行，不犹豫
- 止盈：盈利 > 30% → 分批兑现50%

---

### 维度三：投资逻辑验证

**逻辑标签**（季度现查数据打标签）

| 标签 | 含义 | 判断依据 |
|------|------|---------|
| 价值型 | 低估，等修复 | PE/PB低于历史50分位 |
| 动量型 | 趋势向上，跟涨 | 近6个月跑赢所在市场指数 |
| 防御型 | 稳定收息，不指望涨 | 股息率>3%，波动低 |
| 失效 | 买入逻辑已不成立 | 基本面/估值/行业逻辑已变 |

**机会成本**：持有这只，有没有更好的替代？

**行为自查3问**
1. 上期有没有在大涨后加仓？（追高检查）
2. 波段仓有没有该止损没止的？（处置效应）
3. 有没有持仓"放着不看"超过3个月？（收益黑洞早期信号）

---

### 维度四：归因分析（季度/年度）

**大白话**：我赚的钱，是因为我选股选得好，还是因为整个行业都涨了？

**计算**：每只股票收益 - 所在行业/基准指数收益 = 超额收益（正=选股贡献，负=拖后腿）

**年度额外计算**
- Sortino比率：年化收益 ÷ 下行波动（只看亏钱的月份），> 1.0合格
- Calmar比率：年化收益 ÷ 最大回撤，目标 > 0.83（25%÷30%）

---

### 维度五：组合健康度预判

**现金合理性**：当前现金占比 vs 目标5-15%

**仓位与预期匹配**：预期收益最高的，是否仓位最重？

**预期收益预估**
- 日常：历史估值分位数（这只股票现在贵不贵，相对自己历史）
- 年度：三来源法（分析师一致目标价 + 历史均值回归 + DCF隐含回报率）

**结构预警**：组合加权预期收益 vs 25%年化目标，差距在哪里，如何补
