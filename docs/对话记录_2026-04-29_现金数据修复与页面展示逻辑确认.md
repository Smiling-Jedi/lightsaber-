# 对话记录 2026-04-29：现金数据修复与页面展示逻辑确认

## 背景

Jedi 发现光剑系统持仓页面有两处数据问题：
1. **美股货基显示不准确**：页面显示 53,489 USD，实际应为 68,626 USD
2. **港股现金余额含义不明**：hk_cash = 66,234 HKD 是 4.27 交易后的在途资金，但页面未清晰表达

## 修复过程

### Step 1：根因定位

- `.env` 中 `USD_FUND_AMOUNT=53476` 是旧值，未随实际持仓更新
- 富途API的 `fund_assets` 只返回货基合计（港币计），不区分币种，需要人工输入美元货基金额进行拆分

### Step 2：数据修复

| 参数 | 旧值 | 新值 |
|------|------|------|
| `USD_FUND_AMOUNT` | 53,476 USD | **68,626 USD** |

- 更新位置：`lightsaber/.env`（环境变量，被 .gitignore 排除）
- 更新后港股货基 ≈ 71 HKD，美股货基 = 68,626 USD

### Step 3：页面展示逻辑确认

**Jedi 明确决策**：
> "在页面中，我只需要知道可用现金是多少就可以了，不用管这些现金是不是在途的/是不是货基，只要是我可以用来买股票的钱就可以了。"

**最终规则**：
- 页面只展示**单一"可用现金"数字**（现金 + 货基合并）
- ❌ 不拆分为"现金"和"货基"两行
- ❌ 不标注"在途"标签
- 港股可用现金 = `hk_cash + fund_hkd`
- 美股可用现金 = `us_cash + fund_usd`

**修改文件**：
- `app/templates/positions.html`：标签从"现金余额"改为"可用现金"
- `app/templates/dashboard.html`：移除两处"在途"标签

### Step 4：重复计算确认

确认富途API三个字段**互不重叠**：

| 字段 | 含义 | 币种 | 是否独立 |
|------|------|------|---------|
| `hk_cash` | 港币现金 | HKD | 是 |
| `us_cash` | 美元现金 | USD | 是 |
| `fund_assets` | 货基合计 | HKD | 是 |

- 货基拆分是**减法**关系：`fund_assets - 美元货基×汇率 = 港元货基`
- 两个市场的货基数字来源于同一份 `fund_assets` 的拆分，不是两份独立来源
- **结论：不存在重复计算**
