## 二、发现原力模块仓位计算缺陷

### 缺陷描述
`signal_service.py` 中的 `_calculate_shares` 存在以下问题：
1. **分母错误**：使用"该市场总资产"而非"总资产RMB"计算仓位
2. **静态配置**：`kelly_pct` 来自 `signal_params.json`（2026-03-20回测结果），未结合用户当前画像动态调整
3. **缺失画像约束**：储备金缺口（¥60万）、仓位红线、市场配比上限等未进入信号生成流程

## 三、修复关键系统Bug：富途同步误清空A股持仓

### Bug根因
`futu_sync_service.py` 的 `_mark_closed_positions` 方法会把所有富途未返回的本地持仓标记为清仓。但富途 OpenD**没有A股持仓接口**，导致每次"刷新总资产"时，A股持仓被系统误清空。

### 数据表现
- `portfolio_snapshots`（2026-03-31基线）：总资产 ¥1211.10万
- 当前 `positions` 表手工汇总：总资产仅 ¥919.6万
- 差额约 **¥291万**，主要对应被清空的A股持仓（阳光电源、创业板50ETF等）

### 修复方式
修改 `futu_sync_service.py` 的 `_mark_closed_positions`：
```python
# 修复前：查询所有本地持仓并清仓标记
local_positions = self.db.query(Position).filter(Position.total_shares > 0).all()

# 修复后：只查询富途覆盖的市场（HK/US），保护A股持仓
local_positions = (
    self.db.query(Position)
    .filter(Position.total_shares > 0)
    .filter(or_(Position.stock_symbol.like("HK:%"), Position.stock_symbol.like("US:%")))
    .all()
)
```
