📖 指标说明
EMA：指数移动平均线，短期EMA上穿长期EMA = 趋势转强
MACD：异同移动平均线，MACD柱扩大 = 动量加速，收窄 = 动量减弱
RSI：相对强弱指标，>70超买（不宜追高），<30超卖（或有反弹）
ADX：平均趋向指数，只衡量趋势强度，不判断方向。>40极强，20-40中等，<20震荡（无趋势）。ADX高不代表一定会涨，只说明当前趋势很强
VWAP：成交量加权平均价，过去20个交易日按成交量加权的平均成交价。价格高于VWAP = 溢价，低于 = 折价
OBV：能量潮指标，把上涨日的成交量累加、下跌日的成交量累减。OBV上升 = 资金净流入，下降 = 资金净流出
