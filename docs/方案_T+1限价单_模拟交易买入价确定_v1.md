## 一、背景与问题

当前模拟交易系统使用T日收盘价作为买入价，存在以下问题：
1. 收盘价无法实盘成交（已收盘）
2. 实盘只能T+1日买入，存在跳空风险
3. 需要明确买入价的确定机制，使其可实盘复制

---

## 二、方案概述

**T+1 限价单模式**

```
T日盘后：原力模块生成BUY信号，计算条件单挂价（limit_price）
T+1日盘中：检查最低价是否 ≤ limit_price
  ↓ 是 → 条件单触发，按实际成交价（可能优于limit_price）成交
  ↓ 否 → 信号过期，放弃买入
```

---

## 三、详细流程

### 3.1 T日流程（收盘后）

```
1. 获取T日收盘价
2. 计算技术指标（RSI、布林、EMA等）
3. 判断是否触发BUY条件
4. 【核心】计算建议买入价（根据策略类型）
5. 生成信号记录：
   - action: BUY
   - entry_price: T日收盘价（参考）
   - limit_price: 建议买入价（限价单价格）
   - status: PENDING（待执行）
```

### 3.2 T+1日流程（盘中/收盘后）

```
1. 获取T+1日价格数据（开盘、最低、最高、收盘）
2. 判断：最低价 ≤ limit_price（条件单挂价）？
   ↓ 是 → 条件单触发，按实际成交价（开盘价或limit_price，取更优者）执行B+D分批建仓
   ↓ 否 → 信号过期，status = EXPIRED
3. 记录实际成交价和滑点（用于统计）
```

## 四、建议买入价计算逻辑

### 4.1 按策略类型分类（2026-04-01更新）

| 策略类型 | 触发条件 | limit_price（条件单挂价） | 实际买入价 | T+1成交条件 |
|----------|----------|------------------------|-----------|------------|
| **cyclical**（周期股） | RSI<40 且 收盘价≤下轨 | T日收盘价 | 条件单触发时的成交价（≤T日收盘价） | 最低价≤T日收盘价 |
| **defensive**（防御股） | 收盘价≤下轨×1.015 | 下轨 | 条件单触发时的成交价（≤下轨） | 最低价≤下轨 |
| **large_tech**（大科技） | EMA金叉 | T日收盘价×102% | 条件单触发时的成交价（区间内最低） | 任意价≤收盘×102% |
| **biotech**（医药） | RSI<30 | T日收盘价×102% | 条件单触发时的成交价（区间内最低） | 任意价≤收盘×102% |

**实盘操作**：T日盘后挂限价单，价格=limit_price，T+1日自动成交或过期。

**说明**：实际买入价=条件单触发时的真实成交价（可能优于limit_price），用于计算后续止损/止盈/收益。

### 4.2 计算公式代码（2026-04-01更新）

```python
def calculate_limit_price(close_price, category, indicators):
    """
    计算条件单挂价（limit_price）
    实际买入价 = T+1日条件单触发时的真实成交价（可能优于limit_price）
    
    Args:
        close_price: T日收盘价
        category: 策略类型（cyclical/defensive/large_tech/biotech）
        indicators: 技术指标（含布林下轨、RSI等）

    Returns:
        limit_price: 条件单挂价（保留2位小数）
    """
    bb_lower = indicators.get("bb_lower", close_price)
    
    if category == "cyclical":
        # 周期股：挂T日收盘价，等T+1回调
        return round(close_price, 2)
    
    elif category == "defensive":
        # 防御股：挂下轨，触支撑买入
        return round(bb_lower, 2)
    
    elif category in ["large_tech", "biotech"]:
        # 大科技/医药：挂102%，不追太高
        return round(close_price * 1.02, 2)
    
    else:
        # 默认：按收盘价
        return round(close_price, 2)
```

### 5.4 新增T+1成交检查服务

文件：`app/services/signal_execution_service.py`（新建）

```python
"""
信号执行服务
负责T+1日检查PENDING信号是否成交
"""
from datetime import date, timedelta
from sqlalchemy.orm import Session
from sqlalchemy import func

class SignalExecutionService:

    def __init__(self, db: Session):
        self.db = db

    def check_pending_signals(self):
        """
        检查前一天的PENDING信号，判断T+1是否成交
        应在每日开盘/收盘后调用
        """
        yesterday = date.today() - timedelta(days=1)

        # 获取昨天生成的PENDING状态的BUY信号
        pending_signals = self.db.query(SignalLog).filter(
            SignalLog.action == "BUY",
            SignalLog.status == "PENDING",
            SignalLog.is_simulated == True,
            func.date(SignalLog.generated_at) == yesterday
        ).all()

        for signal in pending_signals:
            # 获取T+1日价格数据
            t1_data = self._get_t1_price_data(signal.symbol)

            if not t1_data:
                continue

            t1_low = t1_data.get("low")
            t1_open = t1_data.get("open")

            # 记录T+1日价格
            signal.t1_low_price = t1_low
            signal.t1_open_price = t1_open

            # 判断成交条件
            if t1_low <= signal.limit_price:
                # 成交！按建议价执行买入
                self._execute_pending_buy(signal)
            else:
                # 未成交，信号过期
                signal.status = "EXPIRED"
                signal.note = f"T+1最低价({t1_low}) > 建议买入价({signal.limit_price})，未触发"

        self.db.commit()

    def _get_t1_price_data(self, symbol: str) -> dict:
        """获取T+1日价格数据（最低价、开盘价等）"""
        # 实现方式：
        # 1. 从数据库获取已刷新的价格
        # 2. 或调用实时数据源获取
        from app.models.stock import Stock
        stock = self.db.query(Stock).filter(Stock.symbol == symbol).first()
        if stock:
            return {
                "low": float(stock.low_price or 0),
                "open": float(stock.open_price or 0),
                "high": float(stock.high_price or 0),
                "close": float(stock.current_price or 0),
            }
        return None

    def _execute_pending_buy(self, signal: SignalLog):
        """执行待执行的BUY信号"""
        from app.services.signal_log_service import SignalLogService

        log_svc = SignalLogService(self.db)

        # 获取T+1日条件单触发时的实际成交价（可能优于limit_price）
        # 如T+1开盘直接低于limit_price，则按开盘价成交
        execute_price = self._get_actual_execute_price(signal)
        
    def _get_actual_execute_price(self, signal: SignalLog) -> float:
        """获取T+1日条件单触发时的实际成交价"""
        # 如果T+1开盘价就低于limit_price，按开盘价成交
        if signal.t1_open_price and signal.t1_open_price <= signal.limit_price:
            return signal.t1_open_price
        # 否则按limit_price成交（价格从高位跌触）
        return signal.limit_price

        # 执行B+D分批建仓
        log_svc._sim_buy(
            symbol=signal.symbol,
            name=signal.name,
            category=signal.category,
            entry_price=execute_price,
            params={},  # 从signal中解析或重新计算
            instruction=None  # 或从signal重建
        )

        # 更新信号状态
        signal.status = "EXECUTED"
        signal.entered = True
        signal.entered_at = datetime.now()
        signal.entered_price = execute_price

        # 记录滑点（用于统计）
        if signal.t1_open_price:
            slippage = execute_price - signal.t1_open_price
            signal.note = f"T+1成交，开盘价{signal.t1_open_price}，成交价{execute_price}，滑点{slippage:.2f}"

        logger.info(f"PENDING信号成交: {signal.symbol} @ {execute_price}")
```

### T+2日及以后

```
如果股价继续上涨：
  - 第二批建仓条件：价格 ≥ 355.28（不回调直接涨）
```

## 七、实盘复制说明

### 7.1 如何在富途/券商APP中复制

```
T日盘后（如19:00）：
  1. 查看光剑系统生成的BUY信号
  2. 记录建议买入价（如355.28）
  3. 在券商APP挂限价单：
     - 股票：Tesla (TSLA)
     - 方向：买入
     - 价格：355.28（T日收盘价）
     - 数量：根据仓位计算
     - 有效期：当日有效（GTD）

T+1日盘中：
  - 如果开盘直接低于355.28（如340）→ 条件单以340成交（更优价格）
  - 如果价格从高位跌至355.28 → 条件单以355.28成交
  - 如果价格始终未触及355.28 → 订单过期，放弃买入

T+1日盘后：
  - 查看光剑系统确认模拟成交情况
  - 对比实盘和模拟的成交差异
```

### 7.2 滑点统计与修正

长期运行后，系统可统计：
```
平均滑点 = SUM(成交价 - T+1开盘价) / 成交次数

例如：
- 平均滑点 = +0.8%（建议价比开盘价高0.8%）
- 模拟收益 = 模拟记录收益
- 实盘预估收益 = 模拟收益 - 0.8%
```

用于评估模拟结果的可复制性。

## 十、策略规则详细说明（2026-04-01确认版）

### cyclical（周期股）

**代表**：Tesla、吉利、建滔、SoFi  
**触发条件**：RSI < 40 且 收盘价 ≤ 布林下轨

| 要素 | 规则 |
|-----|------|
| limit_price（条件单挂价） | T日收盘价 |
| 实际买入价 | 条件单触发时的成交价（≤T日收盘价） |
| T+1成交条件 | 最低价 ≤ T日收盘价 |
| 信号有效期 | T+1日，未成交即过期 |

**示例-Tesla**：
- T日：收盘价350，下轨359.49，RSI 31.8 → 触发信号
- 条件单：挂350
- T+1开盘358，最低345 → 价格触及350时条件单触发，实际成交价=350
- 若开盘直接340（<350）→ 条件单以340成交，实际买入价=340
- T+1最低360 > 350 → 过期，放弃

---

### defensive（防御股）

**代表**：粤海投资、联合健康  
**触发条件**：收盘价 ≤ 布林下轨 × 1.015

| 要素 | 规则 |
|-----|------|
| limit_price（条件单挂价） | 布林下轨 |
| 实际买入价 | 条件单触发时的成交价（≤下轨） |
| T+1成交条件 | 最低价 ≤ 布林下轨 |
| 信号有效期 | T+1日，未成交即过期 |

**示例-联合健康**：
- T日：收盘价270，下轨266，触发价270.19 → 触发信号
- 条件单：挂266
- T+1最低262 → 价格触及266时条件单触发，实际成交价=266
- 若开盘直接260（<266）→ 条件单以260成交，实际买入价=260
- T+1最低268 > 266 → 过期，放弃

---

### large_tech（大科技）

**代表**：腾讯、阿里、Meta、亚马逊  
**触发条件**：EMA金叉

| 要素 | 规则 |
|-----|------|
| limit_price（条件单挂价） | T日收盘价 × 102% |
| 实际买入价 | 条件单触发时的成交价（≤收盘×102%） |
| T+1成交条件 | 任意价格 ≤ T日收盘价 × 102% |
| 信号有效期 | T+1日，未成交即过期 |

**示例-腾讯**：
- T日：收盘价420，金叉形成 → 触发信号
- 条件单：挂428.4（420×102%）
- T+1最高428 → 条件单触发，实际成交价=428（或区间内最低）
- 若开盘直接415（<428.4）→ 条件单以415成交，实际买入价=415
- T+1开盘430 > 428.4 → 过期，放弃（涨太猛不追）

### biotech（医药）

**代表**：百济、Rocket Lab、Circle  
**触发条件**：RSI < 30

| 要素 | 规则 |
|-----|------|
| limit_price（条件单挂价） | T日收盘价 × 102% |
| 实际买入价 | 条件单触发时的成交价（≤收盘×102%） |
| T+1成交条件 | 任意价格 ≤ T日收盘价 × 102% |

**示例-Rocket Lab**：
