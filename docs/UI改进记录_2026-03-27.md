## 技术要点

### Header Band 拉通实现
```html
{# 关键：覆盖 page_wrapper 移除 container 限制 #}
{% block page_wrapper %}
<!-- Header Band - 现在可以 100% 宽度 -->
<div class="ls-header-band">
    <div class="ls-header-inner">
        <!-- 内容限制在 1280px 内居中 -->
    </div>
</div>
{% endblock %}
```

### 样式优先级
- `.ls-header-band` 设置 `width: 100%` 和背景色
- `.ls-header-inner` 设置 `max-width: 1280px` 和 `margin: 0 auto` 实现内容居中
- 这样背景拉通，内容受限
