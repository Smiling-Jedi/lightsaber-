# 光剑系统数据源优先级配置

> 更新日期: 2026-04-03
> 说明: 根据同花顺 iFinD MCP 测试结果更新

---

## 核心原则

| 维度 | 定义 | 说明 |
|------|------|------|
| **持仓同步** | 你账户里实际持有的股票/现金/基金 | 港股/美股/基金走富途API，A股必须你告诉我 |
| **价格更新** | 股价、财报、基本面等市场公开数据 | 优先用同花顺 iFinD，备选其他 |

**重要区分**：持仓同步 ≠ 价格更新
- 持仓同步：知道你有100股腾讯，成本价400
- 价格更新：知道腾讯当前股价是489

---

## 一、持仓同步（你的实际账户数据）

> ⚠️ **只有券商知道你的实际持仓和成本价**，行情软件只能查公开市场价格

### 1.1 持仓股票情况
| 市场 | 数据源 | 获取方式 | 说明 |
|------|--------|---------|------|
| 港股 | **富途OpenD** | API自动同步 | 实际持仓股数、成本价 |
| 美股 | **富途OpenD** | API自动同步 | 实际持仓股数、成本价 |
| **A股** | **用户手动录入** | 截图/口头告知 | ❌ 无API支持，必须你告诉我 |

### 1.2 账户现金
| 现金类型 | 数据源 | 获取方式 | 说明 |
|---------|--------|---------|------|
| HK_CASH | **富途OpenD** | API自动同步 | 港股账户现金余额 |
| US_CASH | **富途OpenD** | API自动同步 | 美股账户现金余额 |
| **A_CASH** | **用户手动录入** | 截图/口头告知 | ❌ 无API支持，必须你告诉我 |

### 1.3 账户内货币基金
| 类型 | 数据源 | 获取方式 | 说明 |
|------|--------|---------|------|
| FUND | **富途OpenD** | API自动同步 | 富途现金宝等货币基金（港币）|

## 二、价格更新（市场公开数据，与持仓无关）

> ℹ️ **价格更新**：查询市场上某只股票的公开价格，与你是否持有无关

### 2.1 实时股价
| 市场 | 优先级 | 说明 |
|------|--------|------|
| A股 | **同花顺iFinD** > Tushare > 新浪财经 | iFinD数据最及时 |
| 港股 | **同花顺iFinD** > 富途OpenD > Tushare | iFinD基本面好，富途价格准 |
| 美股 | **富途OpenD** > 同花顺iFinD > Yahoo | 美股iFinD有延迟，富途实时 |

### 2.2 历史行情
| 市场 | 优先级 | 历史深度 |
|------|--------|---------|
| A股 | **同花顺iFinD** | 15年+ |
| 港股 | **同花顺iFinD** | 10年+（腾讯从2007年）|
| 美股 | **同花顺iFinD** | 10年+（苹果月K线102个月）|

### 2.3 财务报表
| 数据类型 | 数据源 | 历史深度 |
|---------|--------|---------|
| A股财报 | **同花顺iFinD** | 15年+ |
| 港股财报 | **同花顺iFinD** | 15年+（腾讯ROE从2005年）|
| 美股财报 | **同花顺iFinD** | 20年+（苹果从2005年）|

### 2.4 基本面数据
| 数据类型 | 数据源 | 覆盖范围 |
|---------|--------|---------|
| ROE/ROA | **同花顺iFinD** | A股/港股/美股 |
| PE/PB/PS | **同花顺iFinD** | A股/港股/美股 |
| 股东结构 | **同花顺iFinD** | 前10大股东、机构持股 |
| 风险指标 | **同花顺iFinD** | Beta、波动率、夏普、VaR |

### 2.5 宏观/行业数据
| 数据类型 | 数据源 | 说明 |
|---------|--------|------|
| 宏观经济 | **同花顺iFinD EDB** | GDP、CPI、PPI等 |
| 行业数据 | **同花顺iFinD EDB** | 光伏产量、新能源汽车销量等 |

## 四、使用示例

### 4.1 获取账户持仓（必须用富途）
```python
from app.services.futu_sync_service import FutuSyncService

# 获取持仓和现金
sync_service = FutuSyncService()
result = sync_service.sync_positions_and_assets()
# 返回：实际持仓股数、成本价、现金余额
```

### 4.2 获取实时股价（聚合源自动选择）
```python
from app.data_sources.aggregated_source import AggregatedPriceSource

# 自动按优先级选择数据源
source = AggregatedPriceSource()
price = source.get_price("HK:00700")  # 港股优先富途
price = source.get_price("A:300274")  # A股优先iFinD
```

### 4.3 获取基本面数据（用iFinD）
```python
from app.data_sources.ifind_source import iFinDSource

ifind = iFinDSource()

# 获取ROE历史
roe_data = ifind.get_financials("0700.HK", "腾讯控股", ["ROE"], years=10)

# 获取估值
valuation = ifind.get_valuation("0700.HK", "腾讯控股")

# 获取历史行情
history = ifind.get_historical_price("0700.HK", "腾讯控股", period="5年")

# 选股
stocks = ifind.search_stocks("汽车零部件行业市值大于1000亿")

# 宏观数据
macro = ifind.get_macro_data("CPI 202401-202412")
```

## 五、数据源能力矩阵

| 风险指标 | ✅ Beta/VaR | ❌ 无 | ❌ 无 |

## 六、故障转移策略

```
账户数据（持仓/现金）:
  富途OpenD → 失败则报错（无备选，必须人工处理）

实时股价:
  A股: iFinD → Tushare → 新浪财经
  港股: iFinD → 富途 → Tushare → Yahoo
  美股: 富途 → iFinD → Yahoo

基本面数据:
  iFinD → 失败则提示（无备选）
```
